# Paradise Nursery Shopping Application

Paradise Nursery is a complete online plant shop built with React and Redux. The application allows users to browse houseplants, add products to a shopping cart, update quantities, and review a cart total.

## Features

- Landing page with background hero image and Get Started button
- Product catalog grouped into Indoor Plants, Succulents, and Flowering Plants
- Add to Cart buttons that disable after selection
- Dynamic cart count shown in the navigation bar
- Shopping cart page with thumbnail, name, unit price, quantity controls, total cost per item, and overall cart total
- Checkout button with "Coming Soon" message
- Continue shopping link back to the product listing
- About page with company mission and details
